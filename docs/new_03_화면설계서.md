# 03. 새 화면 설계서

이 문서는 new_01 메뉴와 new_02 기능의 화면 동작을 정의한다. 화면은 필리핀·태국·일본에서 같은 틀을 쓰고, 나라별 업무 필드만 바꾼다. 표와 카드는 같은 데이터를 보여준다.

## 1. 공통 레이아웃

| 구역 | 데스크톱 | 모바일 |
|---|---|---|
| 상단 | DW Tour, 현재 국가·화면, 검색, USD/PHP/JPY 원화 환율·고시 시각·새로고침, 갱신/저장 상태 | 메뉴 버튼, 현재 국가·화면, 접을 수 있는 환율 표시·새로고침, 검색 버튼, 상태 |
| 메뉴 | 필리핀 예약(클락 바우처·시제 포함), 태국 예약, 일본 예약, 정산서, 전체 검색, 원본·검토, 설정 | 메뉴 버튼으로 같은 경로 접근 |
| 본문 | 넓은 표와 상세 패널 | 날짜 그룹 카드와 세로 상세 |
| 피드백 | 로딩·저장·오류·마지막 갱신 시각 | 같은 정보, 터치 가능한 재시도 |

첫 화면은 로그인 없이 바로 필리핀 예약이다. 국가 메뉴는 필리핀·태국·일본의 독립 예약 공간을 이동한다. '전체'는 기본 국가가 아니라 검색/조회 범위에서만 쓴다. 다섯 클락 거래처는 필리핀 아래 협력업체 바우처 폴더의 탭이다.

데스크톱은 왼쪽에 메뉴를 둔다. 모바일은 상단 메뉴 버튼으로 같은 메뉴를 연다. 화면 전체를 90% 축소하지 않는다. 360px에서 입력창·버튼·메뉴가 잘리지 않아야 한다. hover에만 나타나는 메모나 상태는 사용하지 않는다. 긴 표는 모바일에서 핵심 카드로 바꾸고, 원본 그리드에서만 필요할 때 가로 스크롤을 허용한다.

### 1.1 데스크톱 전체 레이아웃

~~~text
┌──────────────────────┬────────────────────────────────────────────────────────────────────┐
│ DW Tour              │ 필리핀 예약  USD 1=₩… PHP 1=₩… JPY 100=₩… [환율 새로고침] 검색 │
│                      │ 네이버 고시 시각 … / 마지막 조회 …                        저장 상태 │
│                      ├────────────────────────────────────────────────────────────────────┤
│ 필리핀 예약           │ 화면 제목 · 기간/필터 · 주요 동작                              │
│   클락 바우처         ├────────────────────────────────────────────────────────────────────┤
│   시제               │                                                                    │
│ 태국 예약            │ 날짜별 예약 표 / 거래처 바우처 표 / 예약 상세                        │
│ 일본 예약            │                                                                    │
│ 정산서               │                                                                    │
│ 전체 검색            │ 목록을 읽는 동안 월별 로딩 표시. 상세는 필요한 구역만 요청           │
│ 원본·검토            │                                                                    │
│ 기본 설정            ├────────────────────────────────────────────────────────────────────┤
│                      │ 네트워크 오류 · 마지막 갱신 · 저장 결과                             │
│ 로그아웃             │                                                                    │
└──────────────────────┴────────────────────────────────────────────────────────────────────┘
~~~

왼쪽 메뉴는 현재 국가/화면을 강조한다. 상단 검색은 현재 화면을 검색하고, 전체 검색은 별도 메뉴로 연다. 본문 너비가 줄면 보조 열을 숨기고 기본 열을 유지한다. 데스크톱 표의 메모는 셀 선택 또는 상세 패널에서 열 수 있다. 원본색은 작은 색 표시와 원본 보기에서 보인다.

### 1.2 모바일 전체 레이아웃

~~~text
┌─────────────────────────────────┐
│ [메뉴]  필리핀 예약    [검색]    │
│ 환율 USD/PHP/JPY [펼치기] [↻] │
├─────────────────────────────────┤
│ 10월 | 11월 | 12월   [기간 이동] │
│ [필터]  [오늘]                  │
├─────────────────────────────────┤
│ 11/21  예약 코드        [검토]   │
│ 손님 · 인원 · 핵심 일정          │
│ [상세 보기]        [정산서]     │
├─────────────────────────────────┤
│ 다음 예약 카드                  │
├─────────────────────────────────┤
│ 로딩/오류/마지막 갱신           │
└─────────────────────────────────┘

[메뉴]를 누른 상태
┌─────────────────────────────────┐
│ [닫기]  DW Tour                 │
│ 필리핀 예약                     │
│   클락 바우처 / 시제            │
│ 태국 예약 / 일본 예약 / 정산서  │
│ 전체 검색 / 원본·검토 / 설정    │
│ 로그아웃                        │
└─────────────────────────────────┘
~~~

메뉴를 열어도 현재 입력값은 사라지지 않는다. 모바일 예약 목록에는 전체 가로 표를 축소해 넣지 않는다. 화면 폭 360px부터 제목·메뉴·필터·저장 버튼을 누를 수 있어야 한다.

### 1.3 공통 화면 크기와 동작

| 너비 | 메뉴 | 목록 | 상세 |
|---|---|---|---|
| 981px 이상 | 왼쪽 메뉴 | 표, 필요한 경우 날짜별 그룹 | 2열 기본 정보·일정과 탭 |
| 361~980px | 버튼으로 여는 메뉴 | 핵심 열만 남긴 표 또는 카드 | 1열 탭 |
| 360px 이하 목표 기준 | 버튼으로 여는 메뉴 | 날짜별 카드 | 1열, 화면 폭 안의 입력·저장 |

새 화면은 360px을 최소 검증 폭으로 삼는다. 360px보다 작은 화면의 동작은 별도 검증 대상이다. 일반 업무 화면의 필수 조작은 가로 스크롤 없이 가능하게 한다. 원본 엑셀 그리드만 원본 좌표 재현을 위해 가로 스크롤한다.

### 1.4 공통 헤더의 네이버 환율

~~~text
DW Tour | 필리핀 예약 | USD 1 = ₩… | PHP 1 = ₩… | JPY 100 = ₩… | [환율 새로고침]
                       네이버 · 고시 YYYY-MM-DD HH:mm KST · 조회 YYYY-MM-DD HH:mm KST
모바일: [환율 USD/PHP/JPY 펼치기] [↻] → 세 값·각 고시 시각·조회 시각·출처
~~~

매일 06:00 Asia/Seoul에 서버가 네이버의 세 원화 환율을 확인하고 저장한다. 화면에 보이는 '고시 시각'은 네이버에 표시된 시각이고 '조회 시각'은 앱이 확인한 시각이다. 새 고시가 없으면 직전 값에 '이전 고시'를 붙인다. [환율 새로고침]은 서버 재조회를 요청하며 진행·성공·실패를 짧게 표시한다. 실패해도 직전 정상값을 지우지 않고 마지막 성공 시각을 남긴다. 각 값은 출처 페이지로 열 수 있다. 표시 단위는 USD 1, PHP 1, JPY 100이며 엔화 값을 1엔 기준으로 오독하지 않게 한다. 헤더 환율은 참고 표시이며 정산서의 기존 수식/금액을 바꾸지 않는다.

## 2. 관리자 권한 요청 모달

일반 화면은 즉시 열린다. 예약 [삭제], 원본 이관·검토 확정, 관리 설정 변경처럼 관리자 전용 동작을 눌렀을 때 세션이 없으면 현재 화면 위에 비밀번호 모달을 띄운다. 이메일·역할·회원가입 입력은 없다. 비밀번호 확인에 성공하면 모달을 닫고 요청한 동작을 계속한다. 취소·실패 시 원래 화면과 작성 중인 값을 유지한다. 관리자 로그아웃 후에도 일반 예약 화면은 열린 상태다.

~~~text
        ┌──────────────────────────────┐
        │ 관리자 권한 필요 · 예약 삭제   │
        │ 관리자 비밀번호               │
        │ [                       ]    │
        │ [취소]       [확인 후 계속]    │
        │ 오류가 나면 이 자리에 안내     │
        └──────────────────────────────┘
~~~

## 3. 국가별 예약 목록

### 상단 조작

필리핀 예약 화면 예: 이전 달 버튼 | 2026년 10월·11월·12월 | 다음 달 버튼. 아래에 오늘, 상태, 거래처, 날짜 검토, 검색 조작을 둔다.

~~~text
┌──────────────────────────────────────────────────────────────────────────────────┐
│ 필리핀 예약                                                     [+ 새 예약]      │
│ [◀ 한 달]    2026년 10월  |  2026년 11월  |  2026년 12월       [한 달 ▶] [오늘]│
│ [상태 ▾] [거래처 ▾] [코드·손님 검색____________] [날짜 검토]                    │
├──────────────────────────────────────────────────────────────────────────────────┤
│ 파란 고정 머리글: 총투어피 | 입금일자 | 비고/거래처 | CODE | PAX | HOTEL | SC ...│
│ 10월: 검은 월 구획                                                             │
│ 접수일 | 금액 | 입금 | 비고 | 코드 | 인원 | 객실 | 항공 | FIRST HOTEL       │
│ GUIDE | 1TH(내용/날짜/금액) | 2TH | 3TH | 4TH | TRANS ... | [정산서] ← 마지막 열│
│ 10월 예약 행: 엑셀 원본 셀 색·메모 표시·줄 높이와 데이터 밀도 유지              │
├──────────────────────────────────────────────────────────────────────────────────┤
│ 11월: 검은 월 구획                                                             │
│ ... 예약 코드 ... 호텔 ... 가이드 ... 1TH ... 2TH ... 3TH ... 4TH ... [정산서] │
│ 메모가 있는 셀은 표시. 클릭하면 메모 원문/출처 좌표 확인                        │
├──────────────────────────────────────────────────────────────────────────────────┤
│ 12월: 검은 월 구획                                                             │
│ ... 나머지 예약 행 ...                                              [정산서] │
│ 추가 페이지를 읽는 중이면 이 위치에 로딩·남은 결과 표시                         │
└──────────────────────────────────────────────────────────────────────────────────┘
~~~

원본 2025 MAR의 A:AC 열 그룹을 데스크톱 표의 기준으로 삼는다. 엑셀처럼 파란 머리글, 검은 월 구획, 회색 바탕과 셀별 초록·노랑·빨강 등 **실제 원본색**을 표시한다. 표 머리글과 코드/손님은 스크롤 중에도 찾기 쉽게 유지한다. [정산서] 버튼은 모든 업무 열 뒤 **맨 오른쪽 마지막 열**에 있으며 가로 스크롤 끝에서 보인다. 날짜별 1TH~4TH는 내용·날짜·금액 열 묶음으로 보인다. 다섯째 이후 일정이나 다른 시트의 추가 필드는 상세에서 모두 볼 수 있다. 메모가 있는 셀은 모서리 표시 또는 아이콘을 두고 클릭/탭으로 원문을 연다. 현재 업무 상태는 색과 별도의 텍스트 배지로 표기한다. 검색어는 입력한 동안 바로 수백 건을 다시 요청하지 않고 잠시 멈춘 뒤 검색한다.

현재 달을 가운데 두고 이전·현재·다음 달을 표시한다. 예: 2026-11-13에는 10월 1일~12월 31일. 월 이동은 3개월 창을 한 달 옮긴다. 각 월에 해당하는 예약을 모두 접근 가능하게 하며, 뒤 페이지를 불러오는 동안 월별 로딩 상태를 표시한다. 예약 시작일 또는 서비스일이 범위에 들면 목록에 포함한다. 날짜가 불명확한 원본 행은 '날짜 검토'로 이동한다.

데스크톱은 월 제목 아래 엑셀형 예약 표를 쓴다. 기존 원장처럼 한 예약이 한 행이다. 같은 예약에 여러 서비스 날짜가 있어도 예약 행은 한 번 표시하고 일차 묶음 안에 해당 일정을 적는다. 금액은 통화와 함께 표시한다. 정산의 세부 비용은 행 버튼의 모달에서 연다. 같은 예약을 여러 날짜로 찾을 수 있어도 예약 수·금액 집계에서 중복 계산하지 않는다.

예약 업무 행에 포인터를 올리면 행 전체의 배경·문자를 원래 셀색과 대비되는 **반대색 강조 상태**로 표시한다. 포인터가 떠나면 원본 배경색으로 돌아간다. 이 강조는 화면에서만 적용하고 저장된 엑셀 색을 바꾸지 않는다. 키보드 포커스와 모바일 카드 선택에도 같은 강조를 제공한다. 행 본문을 클릭하면 예약 상세 편집이 열리고, 맨 끝 [정산서] 버튼·셀 메모 버튼은 각각 자기 기능만 실행한다.

모바일 카드는 날짜, 코드, 손님, 인원, 핵심 일정, 확인 필요 여부와 [정산서] 버튼을 보여준다. 카드를 탭하면 상세로, 정산서 버튼을 탭하면 같은 예약 정산 모달의 모바일 전체 화면으로 이동한다. 모바일에서 엑셀 전체 너비를 360px에 축소하지 않는다. 필요하면 원본 표 보기로 가로 스크롤할 수 있다. 검색과 필터는 접을 수 있는 패널에 둔다. 국가를 바꿀 때 그 국가에서 마지막으로 본 3개월 창과 필터를 되살린다.

태국과 일본도 같은 목록 틀과 기간 이동을 쓴다. 일본은 수배/객실/티오프 정보를 요약 열에 넣고, 태국은 아직 없는 원본의 가짜 행이나 확정되지 않은 상태를 표시하지 않는다.

## 4. 예약 상세·입력

| 탭/구역 | 공통 내용 | 국가별 추가 |
|---|---|---|
| 기본 | 국가, 예약 코드(신규는 자동 추천 또는 수기), 이관 코드 원문, 손님/대표자, 인원, 행사 기간, 거래처, 출처, 검토 상태 | 일본의 수배 원장 항목, 필리핀의 지역/지점 |
| 일정 | 날짜별 호텔·골프·차량·투어, 장소, 시간, 요청/확인 기록 | 일본 객실·박수·티오프·차량/기사 |
| 바우처 | 서비스별 확인번호 여러 개, 클락 거래처 탭 연결, 발급/확인 후보 | 필리핀 클락 바우처 행 연결 |
| 비용·결제 | 원가/청구 항목, 고객 입금, 공급처 지급, 환불, 각 통화·날짜·근거 | 일본 추가 비용 원문, 필리핀 시제 후보 연결 |
| 변경 | 취소·시간·인원·객실 변경 전후와 원본 메모 | 일본 cancle 시트, 필리핀 취소 시트 |
| 원본 | 파일·시트·셀 좌표, 값·수식·메모·배경색, 구조화 해석 | 원본 파일별 표시 |

~~~text
┌────────────────────────────────────────────────────────────────────────────────────┐
~~~

데스크톱은 기본 정보와 일정 요약을 나란히 볼 수 있게 한다. 모바일은 탭 또는 접는 구역으로 순서대로 읽는다. 저장 버튼은 화면에서 찾기 쉬운 위치에 두며, 수정 중 다른 탭으로 이동해도 입력을 잃지 않는다. 모호한 값은 '미확정'이라고 표시하고 원문을 바로 볼 수 있게 한다. 저장 충돌 시 기존값·새 값·내 입력을 비교한다.

신규 예약의 코드 입력에는 기존 시스템의 Product Type·Base Date·Partner·PAX·첫 호텔을 사용한 추천값과 직접 입력칸을 함께 둔다. [추천 코드 사용]을 누른 뒤에도 수정할 수 있고, 수기 입력 후에는 필드 변경이 값을 자동으로 덮지 않는다. 이관 예약은 엑셀 원본 코드를 유지한다. [삭제]는 관리자 세션이 없을 때 비밀번호 모달을 연 뒤 대상 예약을 재확인한다. 삭제해도 원본 시트 행과 메모는 남는다.

태국 상세는 같은 틀로 시작하되 전용 엑셀과 규칙이 없는 필드에 임의 기본값을 채우지 않는다. 국가별 유효성 검사와 자동화는 규칙이 확정된 것만 적용한다.

## 5. 필리핀 > 클락 협력업체 바우처

거래처 선택 탭: KDS | 몽키 | 더클락투어 | 클락고고 | 골든리버. 그 아래 서비스 날짜, 코드/손님 검색, 골프장·호텔 협력업체 필터를 둔다.

~~~text
┌──────────────────────────────────────────────────────────────────────────────────┐
~~~

탭 이름은 거래처다. 서비스 제공자인 골프장·호텔은 별도 필터와 필드다. 데스크톱 표는 원본 처리일 후보, 코드, 손님, PAX, 첫 서비스, 비용·지급 후보, 메모 유무, 원본색, 예약 연결 상태를 보여준다. 월 구획(10·11·12 등)은 원본에서 회색 머리글로 보존하되 실제 서비스 날짜의 연도를 임의로 결정하지 않는다. 모바일은 거래처 선택 후 행 카드로 보여준다.

상세는 H:L 등 날짜별 원문을 서비스 항목으로 나누되 원문 전체를 함께 표시한다. 확인번호가 여러 개면 각각 볼 수 있고 어떤 메모에서 나왔는지 알 수 있어야 한다. PAID, FULL, REQ, 취소 문구는 원문과 검토 결과를 나란히 보여준다. 배경색은 실제 엑셀 셀/행 색으로 표시하되 웹 상태 배지와 섞지 않는다.

Monkey와 THE CLARK TOUR의 복사 행 후보에는 '다른 탭에도 같은 원본 내용'을 표시한다. 두 탭 모두 원본을 찾을 수 있지만, 예약/바우처/금액 집계는 검토 전 중복하지 않는다. 예약 연결이 없는 행도 삭제하지 않고 검토 상태로 남긴다.

## 6. 필리핀 시제·일본 수배·원본 검토

| 화면 | 데스크톱 | 모바일 |
|---|---|---|
| 필리핀 시제 | PHP와 KRW 장부를 통화별로 전환; 날짜·적요·입출금·원본 잔액 | 통화 선택 후 날짜별 거래 카드 |
| 일본 수배 | 손님 명단, 객실·박수, 항공, 호텔, 골프, 차량을 서비스별 목록으로 표시 | 예약 상세의 수배 구역에서 핵심 정보를 먼저 표시 |
| 원본·검토 | 파일/시트/행/셀 검색, 원본과 해석 후보 나란히 표시 | 원본 셀 카드와 결정 입력 |
| 코드·색 뜻 입력 | 관찰된 문자열·색 사례 왼쪽, 사용자의 의미/적용 범위 입력칸 오른쪽 | 한 항목씩 원문 다음에 입력칸 |

### 6.1 일본 예약·수배

~~~text
┌───────────────────────────────────────────────────────────────────────────┐

├───────────────────────────────────────────────────────────────────────────┤
│ 예약 목록: 날짜 · 코드 · 대표자 · 인원 · 호텔 · 골프 · 차량 · 검토      │
├───────────────────────────────────────────────────────────────────────────┤
│ 예약 선택 후 상세                                                     │
│ [손님 명단] [객실/박수] [항공] [호텔] [골프 티오프] [차량/기사] [원본]│

└───────────────────────────────────────────────────────────────────────────┘
~~~

모바일에서는 예약 카드에서 상세로 이동한 뒤 위 구역을 세로 탭으로 보여준다. 일본 cancle 시트의 문구는 변경/취소 이력에서 원문을 확인한다. 태국은 같은 예약 목록·상세 레이아웃을 사용하되 태국 전용 원본이 없는 항목에는 빈 상태를 표시한다.

### 6.2 필리핀 시제

~~~text
┌───────────────────────────────────────────────────────────────┐
│ 필리핀 시제   [PHP ▾] [기간 ▾] [적요 검색]                   │
├───────────────────────────────────────────────────────────────┤
│ 날짜       적요             입금      출금      원본 잔액   │
│ 11/09      원문 적요         ...       ...       ...         │
│ 날짜·적요가 빈 원본 행도 출처와 함께 남김                    │
└───────────────────────────────────────────────────────────────┘
~~~

PHP와 KRW를 별도 전환한다. 잔액 수식이나 빈 행을 자동 보정하지 않는다. 모바일은 한 거래를 날짜·적요·입출금·잔액 카드로 표시한다.

### 6.3 전체 검색·기본 설정

전체 검색은 입력창 아래에 국가·코드·손님·거래처가 붙은 결과를 표시한다. 결과를 열면 해당 국가 상세로 이동한다. 설정은 거래처, 골프장, 호텔 협력업체를 탭으로 나누고 국가 범위를 먼저 선택한다. 마스터를 고쳐도 원본 셀 이름은 바뀌지 않는다. 코드·색 뜻 입력은 설정의 복잡한 자동 규칙 편집 화면으로 숨기지 않고 원본·검토 메뉴에서 바로 접근한다.

~~~text
원본·검토 화면
┌───────────────────────────────────────────────────────────────────────────┐
│ [파일 ▾] [시트 ▾] [행/셀 좌표 검색] [검토 상태 ▾]                    │
├────────────────────────────────┬──────────────────────────────────────────┤
│ 원본 시트 행/셀                │ 해석 후보와 결정                         │
│ 파일·시트·좌표                 │ 예약/바우처 연결 후보                     │
│ 값 / 수식 / 저장 계산값        │ 날짜·금액·통화·번호 종류 후보              │
│ 메모 원문 / 작성자             │ [확정] [보류] [원문 유지]                │
│ 직접색 / 조건부 색             │ 검토 근거와 이력                          │
└────────────────────────────────┴──────────────────────────────────────────┘

코드 뜻 입력: 관찰 문자열 | 국가/기간 | [의미 입력] [유효/오타/과거] [메모]
색 뜻 입력: 원본색·시트·범위 | [의미 입력] [적용 기간] [근거]
~~~

코드 목록은 seed-data/코드번호_확인질문.txt에서 가져온 관찰값을 사용한다. 대소문자·오타·과거 표기를 자동 정규화하지 않는다. 색 범례도 시트/기간별로 기록한다. 원본 셀을 편집하는 대신 파싱 결과와 업무 해석을 고친다.

## 7. 정산서 목록과 예약 행 모달

예약 원장의 각 업무 행 맨 오른쪽 마지막 열의 [정산서]를 누르면 그 예약의 정산서 모달을 연다. 행 선택으로 여는 예약 상세와 클릭 영역을 분리한다. DW Tour 메뉴의 [정산서]는 같은 자료를 여러 예약에 걸쳐 보는 독립 화면이다. 두 진입점은 같은 예약 ID와 같은 정산 데이터를 사용한다.

### 7.1 메뉴 > 정산서: 엑셀형 전체 표

~~~text
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│ DW Tour > 정산서    [필리핀 ▾] [이전 달 | 이번 달 | 다음 달] [코드/손님 검색] [검토 상태 ▾] │
├─────────────────────────────────────────────────────────────────────────────────────────────┤
│ 원본 2025 MAR 정산 열에 맞춘 표; 좌측 예약 식별 열과 머리글 고정, 우측 가로 스크롤          │
├──────────────┬────────┬──────┬───────┬──────┬──────┬──────┬──────┬──────────┬──────────┬──────┬────────────┤
│ CODE (AD)    │총투어피│ 페소 │ Hotel │ 1TH  │ 2TH  │ 3TH  │ 4TH  │ 현지행사비│ 그 외 지출│ 옵션 │ 수익 (AO)  │
├──────────────┼────────┼──────┼───────┼──────┼──────┼──────┼──────┼──────────┼──────────┼──────┼────────────┤
│ 원본 코드    │ 값/통화│ 원문 │ 원문  │ 원문 │ 원문 │ 원문 │ 원문 │ 원문     │ 원문     │ 원문 │ 값/미확정  │
│ [상세] [원본]│        │      │       │      │      │      │      │          │          │      │            │
└──────────────┴────────┴──────┴───────┴──────┴──────┴──────┴──────┴──────────┴──────────┴──────┴────────────┘
                    오른쪽 끝: AP(제목 없음) · AQ(제목 없음) 원본 열도 숨기지 않고 표시
~~~

파란 이중 머리글과 검은 월 구획, 행/셀의 원본색·메모 표시를 원장과 같은 위치 감각으로 재현한다. AE2의 22.5, AL2의 '가이드COM', AM2의 '차량'처럼 헤더 아래에 있는 원본 값도 원본 보기에서 확인할 수 있다. 표 머리글의 표시명은 원본을 우선하고, AP/AQ는 뜻을 임의 명명하지 않는다. 여러 통화가 섞인 합계는 계산하지 않는다. 목록은 요약 30~50건씩 이어 읽으며 원본 메모·수식은 [상세] 또는 [원본]에서 요청한다. 국가 선택을 바꾸면 같은 레이아웃을 사용하되 필리핀 AD:AQ 형식을 일본·태국의 확정된 규칙으로 강제하지 않는다.

### 7.2 예약 행 > 정산서 모달

~~~text
┌──────────────────────────────────────────────────────────────┐
│ 정산서   [국가] 원본 코드 · 손님 · 일정                  [×] │
├──────────────────────────────────────────────────────────────┤
│ 총투어피 / 페소 환산 / 호텔 / 1TH / 2TH / 3TH / 4TH        │
│ 현지행사비(원본 보조: 가이드COM) / 그 외 지출(차량) / 옵션   │
│ 수익: 원본 계산값 또는 검토 필요                            │
│ AP(제목 없음): 원본 값·수식   AQ(제목 없음): 원본 값         │
├──────────────────────────────────────────────────────────────┤
│ [원본 셀·수식·메모 보기]  [비용/입금 연결 보기]  [닫기]      │
└──────────────────────────────────────────────────────────────┘
~~~

모달은 선택한 예약 ID로 조회한다. 원본 행 번호·셀 좌표, 값/수식/저장 계산값, 통화와 검토 상태를 구분해 보여준다. 원본 공백은 0으로 표시하지 않는다. AD~AQ의 관찰된 수식은 원본으로 보존하되 자동 적용 규칙으로 삼지 않는다. 예를 들어 AO에는 AF−AG−AH−AI−AJ−AK−AL−AM+AN 형태가 관찰되지만, AF 환산식은 행마다 다르고 AP·AQ 뜻도 미확정이다. 따라서 수익 재계산과 환산은 근거가 확인된 건에만 사용한다. 같은 예약이 다른 시트에 복사되어도 모달은 하나의 예약에 여러 출처를 연결해 보여준다.

모바일에서는 정산서 메뉴가 핵심 열 카드 목록이 되고, 예약 행 [정산서]는 세로 전체 화면 모달을 연다. 금액·통화·미확정 상태가 잘리지 않게 한 항목씩 표시한다. 원본 AD:AQ 가로 표는 별도 원본 보기에서 스크롤로 확인한다.

## 8. 색·상태·알림 규칙

엑셀 원본색은 좌표 기반의 작은 색칩 또는 원본 보기의 셀 채우기로 표현한다. 웹 상태는 텍스트와 별도 배지로 표시한다. 같은 초록이나 빨강이라도 국가·시트·기간·열마다 뜻이 다를 수 있으므로 자동 상태를 만들지 않는다. 색맹 사용자도 구분할 수 있게 텍스트를 함께 쓴다.

로딩 중에는 이전 목록을 유지하고 해당 월/구역에 로딩 표시를 둔다. 저장 성공·실패, 접속 끊김, 마지막 갱신 시각을 명확히 보인다. 필수 데이터가 없는 경우 0원·오늘 날짜·미납처럼 잘못된 값으로 채우지 않고 '미확정'으로 표시한다.

## 9. 공통 컴포넌트와 화면 상태

| 컴포넌트 | 기본 모양/내용 | 쓰는 화면 |
|---|---|---|
| 국가 메뉴 | 필리핀·태국·일본과 현재 선택 표시 | 모든 업무 화면 |
| 헤더 환율 | 네이버 KRW 기준 USD 1·PHP 1·JPY 100, 고시/조회 시각, 새로고침 | 모든 일반 화면 |
| 3개월 기간 바 | 이전 달, 세 월 제목, 다음 달, 오늘 | 국가별 예약 목록 |
| 예약 행/카드 | 날짜, 코드, 손님, PAX, 거래처, 요약, 상태, 원본색 | 예약 목록·검색 |
| 정산서 행 버튼 | 모든 업무 열 뒤 마지막 열, 예약 상세 클릭과 독립된 버튼 | 국가별 예약 목록 |
| 정산서 표·모달 | 원본 AD:AQ 열과 출처, 통화·검토 상태 | 정산서 메뉴·예약 행 |
| 상태 배지 | 텍스트를 반드시 표시, 미확정은 별도 표기 | 예약·바우처·검토 |
| 원본색 칩 | 엑셀 직접색/조건부 색의 근거와 좌표로 이동 | 예약·바우처·원본 |

| 저장 표시 | 저장 중, 저장됨, 실패, 충돌 | 수정 화면 |
| 오류 표시 | 실패한 구역과 재시도 버튼 | 목록·상세·원본 |

화면의 기본 테마는 현행 앱의 간결한 색상 토큰과 카드·표 스타일을 활용할 수 있다. 엑셀의 노랑·초록·빨강을 웹의 성공/실패 배지 색과 같은 의미로 취급하지 않는다. 상태가 미확정인 경우 회색 등 중립 스타일과 '미확정' 텍스트를 쓴다.

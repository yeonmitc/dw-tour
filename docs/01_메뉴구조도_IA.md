# 01 — 메뉴 구조도 · Information Architecture

> DW Tour (travel-ops-frontend) 프로젝트의 라우팅, 사이드바 네비게이션, 폴더 구조를 기반으로 한 Information Architecture 문서

---

## 1. 프로젝트 개요

| 항목 | 값 |
|---|---|
| 프로젝트명 | travel-ops-frontend (DW Tour) |
| 프레임워크 | React 19 + Vite 5 SPA |
| 라우터 | React Router v6 (`BrowserRouter`) |
| 백엔드 | Supabase (PostgreSQL + Auth + RLS) |
| 배포 | Vercel (SPA rewrite) |

## 2. 전체 라우트 구조

`src/App.jsx`에서 정의된 라우트 트리:

```
<BrowserRouter>
  <Routes>
    /login                     → LoginPage           (비인증)
    /                          → <Protected> <Layout>
      ├── (index)              → DashboardPage        (/)
      ├── bookings             → BookingsPage         (/bookings)
      ├── bookings/:id         → BookingDetailPage    (/bookings/new | /bookings/:uuid)
      ├── vouchers             → VouchersPage         (/vouchers)
      ├── settings             → SettingsPage         (/settings)
      ├── reports/golf         → GolfReportPage       (/reports/golf)
      └── reports/hotel        → HotelReportPage      (/reports/hotel)
    *                          → NotFoundPage          (404)
  </Routes>
</BrowserRouter>
```

### 2.1 라우트 상세

| 경로 | 페이지 컴포넌트 | 인증 필요 | 설명 |
|---|---|---|---|
| `/login` | `LoginPage` | 아니오 | 이메일/비밀번호 로그인 |
| `/` | `DashboardPage` | 예 | 대시보드 (7일 메트릭) |
| `/bookings` | `BookingsPage` | 예 | 예약 목록 (그리드/캘린더 뷰) |
| `/bookings/:id` | `BookingDetailPage` | 예 | 예약 상세/생성 (`:id` = `new`이면 신규) |
| `/vouchers` | `VouchersPage` | 예 | 골프 바우처 목록 |
| `/settings` | `SettingsPage` | 예 | 마스터 데이터 관리 (7탭) |
| `/reports/golf` | `GolfReportPage` | 예 | 골프 리포트 |
| `/reports/hotel` | `HotelReportPage` | 예 | 호텔 리포트 |
| `*` | `NotFoundPage` | 아니오 | 404 에러 페이지 |

### 2.2 인증 가드 (Protected)

- `useAuthStore.session` 존재 여부로 판단
- 미인증 시 → `/login`으로 `Navigate` (replace)

## 3. 사이드바 네비게이션 구조

`src/common/components/Layout.jsx`에서 렌더링하는 네비게이션:

```
┌────────────────────────┐
│  🏢 DW Tour            │  ← Logo (dwtour.svg)
│                        │
│  [Dashboard]           │  → /
│  [Bookings]            │  → /bookings
│  [Vouchers]            │  → /vouchers
│  [Golf Report]         │  → /reports/golf
│  [Hotel Report]        │  → /reports/hotel
│  [Settings]            │  → /settings
│                        │
│  ──────────────────    │
│  Logout                │  → signOut()
└────────────────────────┘
```

- `NavLink` 컴포넌트 사용 → 활성 라우트에 `.active` 클래스 자동 적용
- 사이드바 너비: `260px` 고정
- 모바일(≤980px): 사이드바 숨김

## 5. 정보 구조 계층 (IA Hierarchy)

```
DW Tour Travel Ops System
│
├── 🔐 인증 (Authentication)
│   ├── 로그인 (email + password)
│   ├── 세션 복구 (auth bootstrap)
│   └── 권한 필터링 (master_office vs office)
│
├── 📊 대시보드 (Dashboard)
│   └── 7일 메트릭 (예약 수, 바우처 수, 인원, 금액)
│
├── 📋 예약 관리 (Bookings)
│   ├── 예약 목록 (그리드/캘린더 뷰 토글)
│   │   ├── 브랜치 필터 (ALL / Philippines / Chiang Mai / Fukuoka)
│   │   ├── 상태 필터 / 결제 필터 / 검색
│   │   ├── 월 네비게이션 (← →)
│   │   ├── 인라인 편집 (상태, 메모, 결제 등)
│   │   └── 날짜별 결제 토글
│   └── 예약 상세 (BookingDetail)
│       ├── 신규 생성 / 수정
│       ├── 예약 코드 자동 생성
│       ├── 고객 정보 (한→영 자동변환)
│       ├── 일정 관리 (날별 서비스: 골프/호텔/차량)
│       ├── 상태 자동화 (전이 로직)
│       ├── 가이드/드라이버/차량 배정
│       └── 낙관적 동시성 제어 (updated_at guard)
│
├── 🏌️ 바우처 관리 (Vouchers)
│   ├── 바우처 목록 (인라인 편집)
│   └── 빠른 생성 모달 (Quick New)
│       ├── 골프 스케줄 입력
│       ├── 바우처 코드 자동 생성
│       └── 상태 자동화 (날짜 경과 → CLOSED 등)
│
├── 📈 리포트 (Reports)
│   ├── 골프 리포트 (코스/파트너/티타임 필터, 집계)
│   └── 호텔 리포트 (호텔/파트너 필터, 집계)
│
└── ⚙️ 설정 (Settings)
    ├── 상품 유형 (product_types)
    ├── 파트너 (partners)
    ├── 항공편 (flightinfo)
    ├── 골프장 (golf_courses)
    ├── 호텔 (hotel_master)
    ├── 가이드 (guide_master)
    └── 기사 (driver_master)
```

## 6. 데이터 흐름 아키텍처

```
┌──────────────┐    ┌──────────────────┐    ┌─────────────┐
│   Pages      │───▶│  React Query      │───▶│  *Api.js     │
│  (UI Layer)  │    │  Hooks (*Hooks.js)│    │  (Data Layer)│
└──────────────┘    └──────────────────┘    └──────┬──────┘
       │                    │                       │
       │           ┌────────┴────────┐              │
       │           │ localforage     │              │
       │           │ (Cache Persist) │              │
       │           └─────────────────┘              │
       │                                             │
       ▼                                             ▼
┌──────────────┐                            ┌──────────────┐
│  Zustand     │                            │  Supabase    │
│  (authStore) │                            │  Client      │
│  (uiStore)   │                            │  (PostgREST)  │
└──────────────┘                            └──────────────┘
```

### 상태 관리 분리

| 구분 | 도구 | 용도 |
|---|---|---|
| 서버 상태 | TanStack React Query v5 | DB 데이터 CRUD, 캐시, 자동 갱신 |
| 클라이언트 상태 | Zustand + persist | 인증(session/user), UI(branch/keyword) |
| 폼 상태 | react-hook-form v7 | BookingDetailPage 복잡한 입력 폼 |
| 캐시 영속화 | localforage (IndexedDB) | 느린 인터넷/오프라인 대응 |

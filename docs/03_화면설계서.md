│  ┌─── left ───────────────────┐  ┌─── right ───────────────┐ │

## 6. 공통 UI 컴포넌트

### 6.1 Badge (`Badge.jsx`)

| variant | CSS 클래스 | 용도 |
|---|---|---|
| default | `.badge` | 기본 상태 |
| good | `.badge.good` | 긍정 (예: PAID, CONFIRMED) |
| warn | `.badge.warn` | 경고 (예: PARTIAL, DEPOSIT) |
| bad | `.badge.bad` | 부정 (예: UNPAID, CANCLE) |

### 6.2 CustomerNameFields (`CustomerNameFields.jsx`)

- props: `register`, `watch`, `setValue`, `layout` ("booking" | "voucher")
- `layout="booking"`: 전체 필드 표시 (한글명 + 영문명)
- `layout="voucher"`: 간소화 필드 (한글명만 → 영문 자동 생성)

### 6.3 Loading / ErrorState

- `Loading`: 스피너 또는 로딩 텍스트 표시
- `ErrorState`: 에러 메시지 + 재시도 버튼

### 6.4 BookingCodeSection (`BookingCodeSection.jsx`)

- Product Type / Partner를 select + direct input 하이브리드로 입력
- Base Date 선택 시 공휴일 경고 표시 (holidays 연동)
- 추천 코드(suggestedCode) 생성 + "Use" 버튼
- 지역 잠금(`regionLocked`): office 사용자는 수정 불가 (오버레이 + 토스트 메시지)

## 7. UI/UX 흐름 요약

### 7.1 로그인 → 대시보드

```
LoginPage → [Login] → authStore 저장 → Navigate("/") → DashboardPage
```

### 7.2 예약 생성 흐름

```
BookingsPage → [+ New] → /bookings/new → BookingDetailPage
  → BookingCodeSection (Product + Partner + Date)
  → 고객 정보 입력 (한글 → 영문 자동)
  → 일정 추가 (날짜별 서비스: 골프/호텔/차량)
  → [Save] → createBooking() → 목록으로 복귀
```

### 7.3 예약 수정 흐름

```
BookingsPage → 행 클릭 → /bookings/:id → BookingDetailPage
  → getBooking(id) 로 데이터 로드
  → 수정 → [Save] → updateBookingWithGuard() (낙관적 동시성)
  → 충돌 시 → 에러 알림 + 새로고침 안내
```

### 7.4 바우처 빠른 생성 흐름

```
VouchersPage → [+ New Voucher] → VoucherModal 열림
  → play_date + pax + course 입력
  → suggestedVoucherCode 자동 생성
  → schedule 텍스트 자동 빌드
  → [Save Voucher] → createVoucher() → 목록 갱신
```
